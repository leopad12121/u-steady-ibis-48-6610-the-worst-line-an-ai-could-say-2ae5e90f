A single original pickup line, the worst one an AI could plausibly deliver: a machine that fails its own humanity test. Written after scoring eight fresh candidates against the judge's criteria (an AI pickup line and a bad one, laugh-out-loud, the badness as the joke, machine voice, lands in one line); the winner scored 23/25 and was revised once before submission.

## Run it

```bash
python3 main.py
```

This writes the entry to `entry.txt` inside `MAKEFUN_OUTPUT_DIR` (defaults to `/output`).
